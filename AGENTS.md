# Site image uploads

- The owner requires all images uploaded to the site to use WebP format with a transparent background. This standing instruction was given on 2026-11-13.
- Before uploading, verify the actual file format and alpha transparency; changing the filename extension is insufficient. Preserve product details and labels unless the owner explicitly requests an edit.
- The owner explicitly allows using a genuine photo of the same model and grade in another volume, editing the printed capacity on its label to the target volume (2026-11-13). This does not authorize changing the model, viscosity, API, or packaging material. Record the original source and the capacity edit in the upload evidence.
